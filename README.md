HTML5 Semantic Portfolio – Thiranex Internship Task
Project
A multi-page personal portfolio website built with semantic HTML5 and accessibility-focused practices.

Pages
index.html – Home
about.html – About
projects.html – Projects
contact.html – Accessible contact form
css/style.css – Responsive styling
Features
Semantic HTML5 elements such as header, nav, main, section, article, and footer
Skip-to-content link for keyboard users
Keyboard-visible focus states
Accessible navigation with aria-label and aria-current
Proper form labels, required fields and accessible descriptions
Responsive layout
SEO-friendly title and meta description on every page
Open Graph metadata on the home page
No unnecessary JavaScript dependency
How to Run
Download/extract the project.
Open index.html in a browser.
Navigate through all pages using the navigation menu.
Test the contact form with the keyboard using Tab, Shift + Tab, and Enter.
Accessibility / SEO Testing
Use Chrome Lighthouse or another accessibility audit tool.

Target:

Accessibility: 100
SEO: 100
The exact Lighthouse score can vary by browser/version and audit environment, so run the audit after hosting or opening the project.
